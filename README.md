# Git para Sistemas Operacionais e Arquitetura de Computadores

## Apresentação

O **Git** é um sistema de controle de versões distribuído utilizado para acompanhar alterações em arquivos ao longo do desenvolvimento de um projeto.

Nas disciplinas de **Sistemas Operacionais** e **Arquitetura de Computadores**, o Git pode ser utilizado para organizar códigos-fonte, scripts, relatórios, experimentos e diferentes versões das atividades realizadas durante o semestre.

Com o Git, é possível:

- registrar o histórico de alterações de um projeto;
- recuperar versões anteriores de arquivos;
- comparar modificações feitas no código;
- trabalhar em diferentes funcionalidades por meio de *branches*;
- compartilhar projetos por meio de serviços como GitHub e GitLab;
- colaborar com outros desenvolvedores de forma organizada.

## Estrutura típica de um projeto

Um repositório das disciplinas pode conter, por exemplo:

```text
projeto/
├── fontes.arquitetura-computadores: Fontes para a disciplina de Arquitetura de Computadores
│   
│   
└── fontes.sistemas-operacionais: Fontes para a disciplina de Sistemas Operacionais

```
